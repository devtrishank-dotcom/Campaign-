Getting started

1. Sign in

  1. Open the admin panel URL (e.g. http://localhost:5001).
  2. Enter your email and password and click Sign in.
  3. You land on the Dashboard with quick stats and recent campaigns.
The first Super Admin is created with npm run seed. After that, create all other accounts from the panel.
Settings

2. Company & logo

Set your company identity — it appears in the sidebar and is used on tickets and emails.

  1. Go to Settings.
  2. In Company / Branding, click the file field and upload a logo (png, jpg or svg, max 3MB).
  3. Fill in Company name, email, phone, website and Address.
  4. Click Save company details.
Tip: The Company email receives an alert whenever a user raises a support ticket.
  • The uploaded logo and company name appear in the sidebar.
  • The Powered by text appears in the footer at the bottom of every page.
Settings

3. Theme

  1. In Settings → Appearance, click any of the 6 colour swatches.
  2. The whole panel changes instantly and is saved to your account.
Sub-users inherit the admin's theme unless a different theme is set on their user.
Settings

4. Configure providers (Email / WhatsApp / SMS)

You must configure a provider for each channel you want to send on. Credentials are stored encrypted.

  1. Go to Settings → Providers.
  2. Pick a channel tab: Email, WhatsApp or SMS.
  3. Click Add Provider, choose the provider type and fill its fields.
  4. Click Save, then Set active (only one active provider per channel is used).
  5. Click Test, enter a destination and send a test message.
ChannelProvider options
EmailSMTP, SendGrid, Custom HTTP API
WhatsAppMeta Cloud API, Twilio, Custom HTTP API
SMSTwilio, MSG91, Fast2SMS, Custom HTTP API
Custom HTTP API works with any third-party API: give the URL, method, headers and a body template using {{to}}, {{message}}, {{subject}}, {{name}}.
For WhatsApp Meta, add a Webhook Verify Token so delivery status callbacks work.
Settings

5. Sending & contact rules

  1. In Settings → Sending & Contact Rules, tick Restrict sending to a time window and pick start/end times.
  2. Set a Daily limit (0 = unlimited).
  3. Choose your Timezone and a Default country code for contacts.
  4. Click Save sending rules.
If a campaign reaches the window or limit it is automatically paused and resumes when allowed.
Audience

6. Contacts

Add one contact

  1. Go to Contacts → Add Contact.
  2. Enter name, email, phone, pick a country code and tags.
  3. Click Save. Duplicate email/phone is blocked automatically.

Import from CSV / Excel

  1. Click Import. Need the format? Click Example to download a template.
  2. Choose your file (columns: name, email, phone, whatsapp, countryCode, tags).
  3. Optionally add the contacts to a list, then click Import.

Export

Use Export CSV or Export Excel to download all contacts (respects the list filter).

Audience

7. Contact lists

  1. Go to Contact Lists → New List, give it a name and save.
  2. When importing or creating contacts, assign them to lists.
  3. Campaigns target one or more lists.
Content

8. Template categories

Categories are fully dynamic. Defaults are seeded the first time.

  1. Open Templates → New Template and click Manage next to Category.
  2. Type a name and click Add. Click the × on a chip to delete one.
  3. Click Done — your categories now appear in the dropdown.
Content

9. Templates

  1. Go to Templates → New Template.
  2. Enter a name, choose the channel and a category.
  3. Write the message using variables like {{name}}, {{survey_link}}, {{unsubscribe_link}}.
  4. For email you can also add an HTML body (enables open/click tracking).
  5. Click Save.
Content

10. Surveys (feedback forms)

  1. Go to Surveys → New Survey, enter a title and create.
  2. In the Build tab, add questions (single, multiple, yes/no, rating, text) and options.
  3. Click Save Survey, then Activate.
  4. Click Copy public link to share it, or attach the survey to a campaign.
  5. Open the Results tab to see the summary and responses.
Campaigns

11. Campaigns

  1. Go to Campaigns → New Campaign.
  2. Enter a name, pick the channel and optionally a template.
  3. Write the message and select the target lists (click Preview audience to see reach).
  4. Optionally attach a survey and/or set a schedule.
  5. Click Create Campaign, then open it and click Send now (or it sends automatically when scheduled).

On the campaign page

  • Test send — send one message to a number/email before the bulk.
  • Pause / Resume / Cancel — control a running campaign.
  • Retry failed — requeue failed recipients.
  • Export CSV — download the recipient report.
Campaigns

12. Approval workflow

  1. If a user cannot approve (e.g. a Manager), their campaign is created as pending approval.
  2. An admin opens the campaign and clicks Approve (or Reject with a reason).
  3. Only approved campaigns can be sent. A rejected one can be fixed and re-submitted.
Insights

13. Reports & audit

Reports lists the audit trail of every action (who did what and when). Filter by action name.

Each campaign page shows live stats: total, sent, delivered, opened, clicked and failed.

Administration

14. Roles

  1. Go to Roles → New Role.
  2. Enter a name and tick the permissions this role should have.
  3. Click Save. Assign this role to users from the Users page.
Built-in roles (Super Admin, Admin, Manager, Viewer) cannot be deleted. Only a Super Admin manages roles.
Administration

15. Users

  1. Go to Users → New User.
  2. Enter name, email and password, choose a Role and optionally a Colour theme.
  3. Click Save — the user receives a welcome email with their login details.

Bulk import / export

  • Example Excel — download the template.
  • Import — upload a .csv or .xlsx (columns: name, email, password, role).
  • Export CSV / Excel — download the user list.
Admins can create Manager/Viewer/custom users. Only a Super Admin can create admins.
Support

16. Support tickets

  1. Go to Support → Raise Ticket.
  2. Enter a subject, category, priority and describe the issue.
  3. Click Submit Ticket. The company email gets an alert.
  4. Open a ticket to read the thread and reply.
  5. Admins can Close or Reopen a ticket.
Account

17. My profile

  1. Go to My Profile to see your details and permissions.
  2. Use Change Password to update your password.
Deliverability

18. Delivery status (webhooks)

To show real delivered / failed status, point your provider's status callback to the panel.

ProviderCallback URL
Meta WhatsApp Cloud{PUBLIC_BASE_URL}/api/webhooks/meta
Twilio (SMS / WhatsApp){PUBLIC_BASE_URL}/api/webhooks/twilio
Custom HTTP{PUBLIC_BASE_URL}/api/webhooks/custom
  1. For Meta, set a Webhook Verify Token in the provider config and use the same token in the Meta dashboard.
  2. For a custom provider, optionally set a Webhook token and send it as token in the callback body.
  3. Campaign stats then update automatically as recipients receive, open or click messages.
Accounts

19. Multi-tenant & access

One installation hosts many independent accounts. Each account only ever sees its own data.

WhoSees
Super AdminEverything — all admins, users and data
AdminOwn account only; creates sub-users
Manager / ViewerTheir admin's account data
  • Only a Super Admin can create admins.
  • An Admin can create Manager / Viewer / custom-role users.
  • Contacts, campaigns, templates, providers, tickets and settings are all scoped per account.
Help

20. FAQ

My campaign shows “No reachable contacts”.

The selected lists have no subscribed contacts with a valid email (email channel) or phone (WhatsApp/SMS). Add contacts to the list or import them.

Messages are not sending.

Check Settings → Providers: a provider must be active for that channel and its Test must pass. Also check the send window / daily limit.

How do I make a user only see their own data?

Data is isolated automatically per account. Create the user under the right admin — they will only see that account's data.

Why is my campaign “pending approval”?

Your role does not include campaigns.approve. An admin must approve it before it can be sent.

How do I change the panel colours?

Settings → Appearance, click a swatch. A Super Admin can also set a specific theme per user on the Users page.

Emails are not being delivered to users.

Ticket and welcome emails use the active Email provider. Configure and activate one in Settings → Providers.
