01 — Overview

What this platform does

A complete, self-hosted admin panel to run bulk messaging campaigns over Email, WhatsApp and SMS — manage contacts, build campaigns, collect survey responses, track delivery & engagement, and support your users — all with strict multi-account data isolation.

Reach

3 Channels

Email, WhatsApp and SMS from a single campaign builder with pluggable providers.

Scale

Queue Engine

Background queue with concurrency, retries, send windows and daily limits.

Insight

Analytics

Delivery, open and click tracking with per-campaign reports and audit logs.

02 — Architecture

How it works together

A React admin panel talks to an Express API backed by MongoDB. Campaign messages are processed by a background queue that dispatches to whichever provider each account has configured.

03 — Roles & Multi-tenancy

Many accounts, fully isolated

One install serves many independent accounts. Each account (tenant) only ever sees its own data. Roles decide what a user can do.

RoleCan do
Super AdminEverything, all accounts. Creates admins.
AdminOwn account: contacts, campaigns, providers, users, approvals, settings, tickets.
ManagerCreate campaigns and contacts; sending needs approval.
ViewerRead-only dashboards and reports.
Custom rolesDefine any role with a chosen set of permissions.

06 — Channels & Providers

Bring your own provider

Nothing is hard-coded — configure any provider from the panel, set one active per channel, and test it. Credentials are stored encrypted.

ChannelSupported providers
EmailSMTP, SendGrid, Custom HTTP API
WhatsAppMeta Cloud API, Twilio, Custom HTTP API
SMSTwilio, MSG91, Fast2SMS, Custom HTTP API

Custom HTTP provider

Plug in any third-party API with a URL, headers and a body template using {{to}}, {{message}}, {{subject}} and {{name}} placeholders.

07 — Support

Ticket system

Every account user can raise a ticket. Admins see all tickets for their account, reply, and close them — with email notifications both ways.

08 — Settings & Security

Configurable & safe

Encrypted credentials

  • Provider secrets stored encrypted (AES-256-GCM)
  • JWT authentication on every request
  • Role + permission checks on every route
  • Rate limiting on login and public forms

Account controls

  • Multi-tenant data isolation by owner
  • Send window (e.g. 9am–9pm) & daily limit
  • Email List-Unsubscribe header
  • Audit log of all actions

Branding

  • Upload logo & company details
  • Company email receives tickets
  • 6 colour themes per account
  • Default country code for contacts

Delivery

  • Webhooks for delivered / failed status
  • Automatic retries with backoff
  • Open pixel & click redirect tracking
  • Unsubscribe handling

10 — Quick Start

Run it in minutes

Local development

Backend on :5000, admin panel on :5001.

cd backend
cp .env.example .env
npm install
npm run seed
npm run dev

cd frontend
npm install
npm run dev

Docker

One command for the whole stack.

docker compose up -d --build
docker compose exec backend npm run seed
# open http://localhost:8080
